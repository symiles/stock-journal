How to set up Google Sheets sync
One-time setup (5 minutes) 1. Go to script.google.com and create a new project
2. Paste the Apps Script code (tap "Copy script" below)
3. Click Deploy → New deployment → Web app
4. Set "Who has access" to Anyone, then Deploy
5. Copy the Web App URL — paste it as your "Sheet ID" above
6. Create a Google Sheet and copy its ID from the URL
7. Paste the Sheet ID into the script's SHEET_ID constant
